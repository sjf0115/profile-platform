# 任务架构重构方案

## 目标架构

```
Controller (薄层路由)
    |
    +---> XxxService (完整用例: 元数据 CRUD + 基础设施操作)
    |
    +---> TaskExecutionService (执行编排: 创建实例 -> Executor -> 更新状态)
              |
              +---> XxxTaskExecutor (策略实现, 调用 XxxTask)
                        |
                        +---> XxxTask (独立执行逻辑)
```

## Task 1: 重构 DatasetService -- 合并基础设施操作

**文件**: `profile-web/.../service/DatasetService.java`

**变更内容**:
1. 新增依赖注入: `AnalysisEngineService`, `TaskService`
2. `createDataset()` 方法末尾追加:
   - 调用私有方法 `buildEngineTable(dataset)` 创建引擎表
   - 调用私有方法 `createSyncTask(datasetId, datasetName)` 创建同步任务
3. `updateDataset()` 方法末尾追加:
   - 调用私有方法 `rebuildEngineTable(dataset)` 更新引擎表 Schema
4. `delete()` 方法中追加:
   - 调用 `analysisEngineService.dropDatasetTable(datasetId)` 删除引擎表
   - 调用 `taskService.deleteByRelatedId(datasetId)` 删除关联同步任务
5. 新增三个私有方法: `buildEngineTable`, `rebuildEngineTable`, `createSyncTask`
6. 移除 `// Todo 底层引擎相关也需要删除` 注释

**关键代码**:
```java
private String createDataset(Dataset dataset) {
    // ... 现有元数据保存逻辑 ...
    datasetMapper.insertSelective(dataset);
    // 基础设施操作
    buildEngineTable(dataset);
    createSyncTask(datasetId, dataset.getDatasetName());
    return datasetId;
}
```

## Task 2: 精简 DatasetTask -- 仅保留独立执行逻辑

**文件**: `profile-web/.../task/DatasetTask.java`

**变更内容**:
1. 移除引擎表操作方法: `createEngineTable`, `updateEngineTable`, `dropEngineTable`, `getEngineTableName`
2. 移除同步任务创建方法: `createSyncTask`
3. 移除实例状态更新方法: `updateInstanceStatus` (TaskExecutor 回调直接调用 DatasetService)
4. 移除依赖: `DataSourceService`, `AnalysisEngineService` (不再需要)
5. 新增方法: `executeSync(String datasetId)` -- 委托 `DiEngineService.executeDatasetSync()`
6. 保留: `configureScheduler`, `getSchedulerConfig` (用户手动操作，独立于 CRUD)

**精简后 DatasetTask 方法列表**:
- `executeSync(datasetId)` -- 被 ImportTaskExecutor 调用
- `configureScheduler(datasetId, config)` -- 用户手动配置调度
- `getSchedulerConfig(datasetId)` -- 获取调度配置

## Task 3: 更新 DatasetController -- 移除编排逻辑

**文件**: `profile-web/.../controller/DatasetController.java`

**变更内容**:
1. `save()` 方法简化: 直接调用 `datasetService.save()`, 不再调用 `datasetTask.createEngineTable/createSyncTask/updateEngineTable`
2. `delete()` 方法简化: 直接调用 `datasetService.delete()`, 不再调用 `datasetTask.dropEngineTable`
3. 调度相关端点不变: `getSchedulerConfig` / `configureScheduler` 仍调用 `datasetTask`

**简化后的 save()**:
```java
@PostMapping(value = "/save")
public Response save(@RequestBody Dataset dataset) {
    String datasetId = datasetService.save(dataset);
    return Response.success(datasetId);
}
```

## Task 5: 创建 ImportTaskExecutor

**新建文件**: `profile-web/.../task/executor/ImportTaskExecutor.java`

```java
@Component
public class ImportTaskExecutor implements TaskExecutor {
    @Resource private DatasetTask datasetTask;
    @Resource private DatasetService datasetService;

    public SchedulerJobType getType() { return SchedulerJobType.IMPORT; }

    public void execute(ExecutionContext context) throws Exception {
        datasetTask.executeSync(context.getRelatedId());
    }

    public void onSuccess(String relatedId, TaskInstance instance) {
        datasetService.updateInstanceStatus(relatedId, InstanceStatus.SUCCESS.getCode(), "同步成功");
    }

    public void onFailure(String relatedId, TaskInstance instance, Throwable error) {
        datasetService.updateInstanceStatus(relatedId, InstanceStatus.FAILED.getCode(), error.getMessage());
    }
}
```

## Task 6: 创建 GroupTaskExecutor

@Component
public class GroupTaskExecutor implements TaskExecutor {
    @Resource private GroupTask groupTask;
    @Resource private GroupService groupService;

    public SchedulerJobType getType() { return SchedulerJobType.GROUP; }

    public void execute(ExecutionContext context) throws Exception {
        groupTask.executeGroupSelection(context.getRelatedId());
    }

    public void onSuccess(String relatedId, TaskInstance instance) {
        groupService.updateInstanceStatus(relatedId, InstanceStatus.SUCCESS.getCode(), "执行成功");
    }

    public void onFailure(String relatedId, TaskInstance instance, Throwable error) {
        groupService.updateInstanceStatus(relatedId, InstanceStatus.FAILED.getCode(), error.getMessage());
    }
}
