# 任务监控告警全栈实现

## Task 1: 数据库与枚举

**数据库改动** (`profile-web/src/main/resources/sql/init.sql`)：
- `profile_meta_task` 表 CREATE TABLE 中 `upstream_task_ids` 与 `source_type` 之间插入 3 列：
  ```sql
  `alert_condition` VARCHAR(20) COMMENT '告警触发条件:failure/success/finished(空=未配置)',
  `alert_channels` VARCHAR(100) COMMENT '报警方式(逗号分隔):sms,email,phone,dingtalk,webhook',
  `alert_receivers` VARCHAR(1000) COMMENT '接收人JSON:[{"type":"owner"},{"type":"user","value":"userId"}]',
  ```
- 末尾追加 `profile_meta_alert_history` 表（history_id, task_id, instance_id, alert_condition, alert_channel, receivers, subject, content, send_status, send_message, creator, modifier, 时间戳）

**枚举** (`profile-common/.../enums/`)：
- `ModelType` 追加 `ALERT("25", "告警")`
- 新建 `AlertCondition`：FAILURE/SUCCESS/FINISHED，含 `isMatch(InstanceStatus)`
- 新建 `AlertChannel`：SMS/EMAIL/PHONE/DINGTALK/WEBHOOK，含 `isImplemented()`（仅 EMAIL=true）
- 新建 `AlertReceiverType`：OWNER/USER，预留 GROUP/ROLE

## Task 3: 告警触发与发送

**AlertService** (新建 `profile-web/.../service/AlertService.java`)：
- 注入：`SystemConfigService`、`NotificationManager`、`TaskService`、`UserService`、`AlertHistoryMapper`
- `void trigger(Task task, TaskInstance instance, InstanceStatus status)`：
  1. `instance.triggerMode == MANUAL` → return
  2. 读 task 告警配置，无配置 → return
  3. `AlertCondition.isMatch(status)` → 不命中 → return
  4. 解析 `alert_channels`，非 email 的跳过并落 send_status=2 记录
  5. `resolveReceivers(task)` → 解析 JSON → 按 type 分派取 userId → `userService.getDetail` 取 email → 去重去空
  6. `systemConfigService.getConfigByGroup("smtp")` → `JSONUtils.toJsonString` → `NotificationSenderConfig.config`
  7. 构建 `NotificationMessage`（subject + HTML content）
  8. 构建 `NotificationReceiverConfig`（`{"to":"a@x.com,b@x.com","cc":""}`)
  9. `notificationManager.notify(message, {sender:{receiver}})`
  10. 落 `profile_meta_alert_history`
- 整体 try/catch，异常仅记日志+落失败记录

**TaskExecutionService.executeAsync 集成**：
- 注入 `AlertService`
- 成功分支 `markSuccess` 后：`try { alertService.trigger(task, instance, SUCCESS); } catch ...`
- 失败分支 `onFailure` 后：`try { alertService.trigger(task, instance, FAILED); } catch ...`

**detail.vue 新增**：
- 告警配置卡片（`el-descriptions` 展示：触发条件、报警方式 tag、接收人）
- 编辑对话框（`el-dialog` 600px）：
  - 触发方式区：触发条件下拉（failure/success/finished）
  - 报警行为区：info 提示条 + 报警方式多选（email 可选，其余 disabled+tooltip）+ 接收人（任务责任人 checkbox + 其他下拉选人）
- 提交组装：channels 数组→逗号串，receivers 条目数组→JSON
- 回显解析：channels 逗号串→数组，receivers JSON→勾选/选人回填
